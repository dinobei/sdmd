# ΔΣ (Sigma-delta) 모션 디텍션 라이브러리

## 1. 소개
커스터마이징 가능한 모션 디텍션 알고리즘 구현
임베디드에서도 실시간으로 사용 가능한 연산량을 가지도록 함 (NEON 지원, 멀티코어)

## 2. 기능
커스터마이징 가능한 옵션(stride, N, ...)
관심영역(들)만 모션 디텍션 (추가 예정)
	관심영역별 디텍션 결과 확인?
NEON 지원
멀티코어 지원 가능

## 3. 옵션
stride : density/연산량 조절
N : 필요시 이미지센서별로 최적화를 위해 2의 승수로 설정. (보통 1-4의 값을 가짐)
